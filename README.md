# Windows 灵动岛 (Dynamic Island for Windows)

专为 Windows 桌面打造的现代暗黑玻璃质感**灵动岛（Dynamic Island）**。常驻于屏幕顶端，带来丝滑顺畅的形变动画与全方位的日常效率体验。

---

## 🌟 核心特色与功能更新

### 1. 🕒 高对比度清晰时间显示与自由拖拽定位
- **随心自由拖动**：收起状态的胶囊支持鼠标按住随意拖拽到屏幕任意位置，松开自动保存记忆，点击即可瞬间展开控制中心。
- **独立时钟药丸胶囊**：灵动岛收起态左侧常驻独立高对比度时间标签（`15:30`），纯白粗体加深色边框衬底，任何壁纸下均清晰可见。
- **大岛控制中心时间**：面板顶部实时时钟字号加大至 `14px / 16px`，采用高亮青蓝配色与粗体白字秒针刷新。
- **卡片倒计时色块标记**：待办事项卡片摒弃暗色低对比度文字，采用高饱和度色块标签：
  - ⚠️ **已超时**：高亮红底标签（如 `⚠️ 超时 15分钟 · 14:30`）
  - ⏳ **即将到期 (<1小时)**：活力琥珀黄底标签（如 `⏳ 仅剩 25分钟 · 15:30`）
  - ⏰ **正常安排**：天空蓝醒目标签（如 `⏰ 18:00`）

---

### 2. 📋 模块化极简时间设定器（彻底告别生硬难用的时间输入框）
- **专为待办场景打造的 `FriendlyTimePicker`**：
  - 彻底淘汰了 Qt 原生 `QDateTimeEdit` 中按键卡死、光标乱跳（如输年份误跳至0001年）等极其反人类的输入缺陷。
  - **日期快捷胶囊 + 独立日期面板**：提供 `[ 今天 ]`、`[ 明天 ]`、`[ 后天 ]` 一键点选，亦可点击日历图标随意点选任意月历天数。
  - **清晰分离的时与分选择器**：
    - 提供常用时段快捷选择：`[ 09:00 ]`、`[ 12:00 ]`、`[ 15:00 ]`、`[ 18:00 ]`、`[ 21:00 ]`。
    - 独立小时下拉框（00~23）与分钟下拉框（支持5分钟步进或键盘随意键入），彼此独立，永不冲突。
  - **实时人话预览气泡**：
    - 实时动态显示高对比度反馈（如：`⏰ 提醒时间: 2026-11-11 15:30 (明天到期 · 约 23 小时后)`）。
  - **自然语言输入无缝同步**：输入框输入 `明天下午3点开会` 时，时间选择器所有胶囊与下拉框自动智能对齐同步！

---

### 3. ⏰ 独立周期闹钟中心 (支持 iOS 滑动开关、🎯 周期打卡与 ⏳ 延时贪睡机制)
- **彻底告别待办与闹钟混杂**：
  - 待办（Todo）与周期闹钟（Alarm）彻底分流，普通待办专注于“做完打勾划掉”，周期闹钟专注于“循环规则与定时提醒”。
- **iOS 风格极简滑动开关 (Toggle Switch)**：
  - 闹钟卡片左侧配备原生滑块开关，可随时一键【开启运行】或【暂停休眠】，不再有“点击圆圈无效”的困惑。
- **🎯 周期打卡机制 (Check-in Streak)**：
  - 每期闹钟支持一键打卡，自动记录累计打卡次数与上次打卡时间，完成后自动平滑推延至下一周期。
- **⏳ 延时贪睡机制 (Snooze Delay)**：
  - 支持快捷延时（5分钟、10分钟、30分钟、1小时），胶囊条与大岛实时展示醒目黄色延时状态，随时可一键取消或恢复。
- **自定义周期规则**：
  - 支持【每天重复】、【工作日】、【每周自定义 (可任意勾选周一至周日多选)】与毫秒级防漏提醒。

---

### 4. 💧 习惯养成与喝水提醒专栏 (区间循环、自定义下次提醒时长)
- **专为喝水/久坐起立等高频健康习惯打造**：
  - 解决常规闹钟无法灵活处理“几点开始到几点结束”以及“喝完后灵活决定多久后再提醒”的痛点。
- **可配置活跃时间段**：
  - 自定义开启时段（如早 `09:00` 至晚 `18:00`），下班或夜晚自动静默不打扰，隔天上班时段自动恢复。
- **动态交互式弹窗提示**：
  - 提醒触发时，弹窗提供多种下次间隔一键选择：`[ 💧 30分后 ]`、`[ 45分后 ]`、`[ 60分后 ]`、`[ 90分后 ]`，点选即打卡并自动定好下次闹钟。
- **目标进度可视化与系统托盘快速打卡**：
  - 卡片实时显示今日已喝水杯数与目标进度条；系统托盘右键直接支持 `💧 快速喝水打卡 (+1)`。

---

### 5. 🎵 本地音乐播放器 (灵动岛沉浸式交互)
- **原生多媒体解码**：基于 `PyQt6.QtMultimedia`，支持 `.mp3`, `.wav`, `.flac`, `.ogg`, `.m4a`, `.aac`, `.wma`。
- **全功能控制面板**：
  - 单曲与整文件夹批量导入。
  - 循环模式切换：`🔁 列表循环`、`🔂 单曲循环`、`🔀 随机播放`。
  - 毫秒级可拖动进度条、当前/总时长、音量滑块调节。
  - 播放列表记忆与持久化保存（重启不丢失）。
- **灵动岛胶囊联动**：
  - 音乐播放时，收起态胶囊实时展示 `🎵 正在播放: 歌曲名`。
  - 胶囊栏直接内置 **迷你播放/暂停按钮**，无需展开即可一键切歌暂停！

---

### 6. ⚡ 实时硬件监控 (System Performance Monitor)
- 实时监测 CPU 处理器使用率与多核状态、RAM 内存占用与磁盘健康度。
- 胶囊栏自带变色预警角标（低负荷青蓝、中负荷橙黄、高负荷警示红）。

---

### 7. 📝 灵感便签 (Quick Memo / Scratchpad)
- **输入实时自动防抖保存**，支持一键复制全部内容至剪贴板。

---

### 8. ⚙️ 开机自启与静默常驻 (Windows Startup)
- 在「⚙️ 设置」面板中可一键勾选 **「开机自动启动灵动岛」**。
- 基于 Windows 注册表标准接口（`HKCU Run`），自动调用 `pythonw.exe` 启动，开机即用，零控制台黑框打扰。

## 🚀 启动与运行

### 运行环境
- Windows 10 / 11
- Python 3.9+ (已在 Python 3.12 验证)

### 安装依赖 (支持新电脑全自动安装)
- **免手动安装**：直接双击 **`run.bat`**，程序会自动检测当前环境缺少的依赖包（如 `PyQt6`、`psutil`），并通过国内高速镜像源（清华源/阿里源）自动下载安装并启动，无需任何手动操作。
- **手动安装方式**：
### 快速开始（无需提前配置环境，双击即用）

无论是在自己电脑还是**分享给其他人**，只需双击运行即可，脚本已内置全套环境自愈逻辑：

#### 方式一：双击 `run.bat` (最推荐，初次运行与日常使用通用)
- **首次运行**：
  1. 脚本将自动按优先级深度扫描系统中的原生 Python（优先匹配官方 `py -3`、`%LOCALAPPDATA%`、`Program Files`、`Conda` 等路径，自动避开 MSYS2 / MinGW / Windows 商店快捷方式）。
  2. 自动在本地创建独立的隔离虚拟环境（`.venv`），**不污染全局系统，无需管理员权限**。
  3. 自动连接国内超高速镜像源（清华大学源/阿里云源）下载安装 `PyQt6` 与 `psutil`。
  4. 自动在后台启动灵动岛常驻于屏幕顶端，并自动退出控制台窗口。
  5. *若电脑未安装 Python，脚本会自动检测 Windows 官方 `winget` 并提示一键全自动安装，或自动打开官网下载。*
- **日常运行**：
  - 依赖检查通过后秒级静默启动，无需等待。

#### 方式二：双击 `启动灵动岛.vbs` (彻底纯静默启动，无任何黑框)
- 适合创建桌面快捷方式，日常双击直接无黑框唤起灵动岛。

#### 方式三：开发者调试模式
- 在终端执行：`run.bat --debug`，控制台将实时打印运行日志，方便排查问题。
